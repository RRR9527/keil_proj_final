# 任泽楷8.10作业

## 读取代码，理解种子代码

首先定义了结构体 `command_packet`
```c
typedef struct
{
    uint8_t header[2];  
    uint8_t cmd;         
    uint8_t checksum;   
} command_packet;
```
这个结构体用于储存信息。分别由`header`来核验是否合法，`cmd`记录了LED闪烁的次数和LED的编号。`checksum`是另一个检验信息的。这三个一起构造出了command_packet这个对象。

随后定义结构体`packet_queue`
```c
typedef struct
{
    command_packet buf[PACKET_QUEUE_SIZE];
    uint8_t        head;
    uint8_t        tail;
    uint8_t        count;
} packet_queue;
```
其中，`buf[]`是一个数组，用于储存之前定义的`command_packet`的实例。

后续的读取/写入，都是把`command_packet`的实例储存入数组`buf[]`。而循环结构的应用正式对这个数组进行的。今日所学习的位运算则是用于处理`command_packet`中的信息。

位运算的说明：

| 运算符 | 名称 | 规则 | 实战 |
| :--- | :--- | :--- | :--- |
| **`&`** | **按位与** | 都为1时返回1，其余时候返回0 | 解包时用 `pkt->cmd & 0x0F`，把高 4 位清零，只留下低 4 位的 LED 掩码。 |
| **`\|`** | **按位或** |都为0时返回0，其余时候返回1 | 拼贴两个`header` |
| **`^`** | **按位异或** | 不同为1，相同为0 |  |
| **`~`** | **按位取反** | 0变1，1变0 |  |
| **`<<`** | **左移** | 右边补0 | 拼贴两个`header`，高位先补0 |
| **`>>`** | **右移** | 删掉右边的几位数 | 解包时 `pkt->cmd >> 4`，把高 4 位的闪烁次数搬到低 4 位来，变成普通的数字 0~15。 |

#### 调试过程

1. `main.c`报错：在`main.h`加入定义后解决。
```c
#define LED_MASK_LED1 0x01u
#define LED_MASK_LED2 0x02u
#define LED_MASK_LED3 0x04u
#define LED_MASK_LED4 0x08u
```

2. 连接后还是不能正常亮灯。仔细检查代码逻辑，发现是返回值和修改tail的顺序发生了错误。应该先进行判断，写入数据，最后再把tail往后移。修改完成后，代码正常运行。
